# dore-memory

Local long-term memory for Claude Code. Say it once, it remembers in every new session.
Runs on your machine, nothing leaves it. macOS and Linux.

```bash
npx dore-memory install     # set up dore + the Claude Code plugin
npx dore-memory status      # check it
npx dore-memory update      # upgrade
npx dore-memory uninstall   # remove (your memory is kept)
```

Needs Node 18+, Claude Code, and `uv` or Python 3.11+.
Source and docs: https://github.com/SopheaII/dore-memory
